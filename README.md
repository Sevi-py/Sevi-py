## Featured projects

### [Stayvera](https://stayvera.com)

Premium rental and group-travel software focused on fair host economics, transparent fees, host support, instant listing import, and AI-powered guest operations.

### [tnyr.me](https://tnyr.me) · [source](https://github.com/Sevi-py/tnyr.me)

A privacy-focused URL shortener where sensitive work happens in the browser. The server stores only a storage key and encrypted destination data, so original links stay private by design.

### [Coolify Codex Plugin](https://github.com/Sevi-py/coolify-codex-plugin)

Codex plugin for controlling Coolify Cloud and self-hosted Coolify instances through a local MCP server.

### [DueChime](https://duechime.flarely.at/)

A calendar-based reminder app for iPhone that keeps reminders alongside their dates, with optional alarm-style alerts, sound, and snooze. Reminders stay on the device, and no account is required.
